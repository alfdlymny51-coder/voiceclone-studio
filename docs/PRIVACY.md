# سياسة الخصوصية والامتثال — VoiceClone Studio

## المبادئ

1. **لا استنساخ دون موافقة موثّقة**: كل مشروع يتطلب إقراراً ثلاثياً (ملكية/تفويض، موافقة على النص، تحمّل المسؤولية) قبل رفع أي عيّنة. يُخزَّن الإقرار في سجل التدقيق مع الطابع الزمني.
2. **تشفير التخزين**: جميع العيّنات والمخرجات مشفّرة بـ Fernet (AES-128-CBC + HMAC). المفتاح عبر `VCS_STORAGE_KEY` فقط — لا يُحفظ في الكود أو المستودع.
3. **سجل تدقيق غير قابل للتعديل**: كل حدث (إنشاء مشروع، موافقة، رفع، تدريب، توليد، حذف) يُسجَّل في سلسلة SHA-256 hash-chain يمكن التحقق من سلامتها عبر `GET /api/audit/verify`.
4. **كشف الإساءة**: حدود معدل (rate limiting)، عدّاد مخالفات لكل فاعل، وإنذار `abuse_alert` تلقائي عند تجاوز العتبة — قابل للربط ببريد أو Webhook.
5. **الإفصاح**: يجب أن تحمل الأصوات المولّدة إفصاحاً بأنها اصطناعية عند نشرها.
6. **الحق في الحذف**: حذف العيّنة يحذفها من التخزين المشفّر فوراً (حق النسيان).

## التزامات المشغّل

- فعّل HTTPS دائماً في الإنتاج (ضع الخدمة خلف reverse proxy مثل Caddy/Nginx).
- ولّد مفتاح تشفير قوي: `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`
- قيّد CORS على نطاقك فقط عبر `VCS_CORS_ORIGINS`.
- راجع سجل التدقيق دورياً وحقّق في أي `abuse_alert`.
- لا تستخدم النظام لانتحال شخصيات عامة أو التضليل الإعلامي أو الاحتيال — هذا يعرّضك للمساءلة القانونية.
